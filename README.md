# Car Racer:

This is the 2d online car racing game which is playable score tracker,you can choose difficulty also default is medium. Made by Arpan Poudel.

You can play live demo:(https://2dcarracerbyarpan.netlify.app)


## Built by:

**HTML**

**CSS**

**JS**

## features:

 **You can choose level difficulty**

 **Easy hard and normal levels**

 **Score tracking**
